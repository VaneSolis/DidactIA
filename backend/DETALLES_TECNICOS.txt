Nuevas funciones:

1. generateCacheKey(params)

   - Base64 encoded

2. getFromCache(params)
   - Busca actividades en caché

3. saveToCache(params, data)
   - Guarda actividades con timestamp
   - Para reutilización posterior

Ejemplo:
```

if (cached) return res.json({ ..., modo: 'IA (caché)' });
```


✅ SECCIÓN 4: Función de Reintentos (Líneas ~80-120)
────────────────────────────────────────────────────

Nueva función: fetchWithRetry(apiUrl, options, retryCount = 0)

Características:
- Reintenta hasta 3 veces
- Exponential backoff
- Detecta error 429 específicamente
- Logs con emojis

Flujo:
1. Intenta fetch
2. Si error 429 y hay reintentos → espera y reintenta
3. Si otro error → retorna error
4. Si éxito → retorna respuesta

Ejemplo de uso:
```
const { response, rawResponse, error } = await fetchWithRetry(
  apiUrl,
  { method: 'POST', headers: {...}, body: {...} }
);
```
